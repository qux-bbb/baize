Baize (白泽) · EDR 架构

白泽识妖 · Rust Agent → gRPC → Go Server → ES + React Dashboard

Agent · Rust

  • • 用户态遥测采集（ETW / auditd）
  • • 进程、文件、网络、注册表全量监控
  • • 内置 YARA 扫描引擎
  • • gRPC 双向流上报事件 & 接收指令
  • • 跨平台：Windows + Linux

Server · Go

  • • gRPC 事件管道 + Agent 生命周期管理
  • • 检测引擎：Sigma 规则 + YARA + IOC 匹配
  • • 响应模块：隔离、杀进程、删文件、跑脚本
  • • REST API 供 Dashboard 调用
  • • 单二进制部署，前端内嵌

存储 & Dashboard · ES + React

  • • Elasticsearch：全量遥测 + 告警索引
  • • 全文检索支撑狩猎查询
  • • React Dashboard：主机列表、告警、时间线
  • • 进程溯源图可视化
  • • 规则管理与一键启停
